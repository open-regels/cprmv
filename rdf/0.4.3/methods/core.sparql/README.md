# core.sparql

The core.sparql method is a publication method that serves as a basis for the support retrieval of RuleSet's that have been published and are retrieveable through an SPARQL endpoint.

TOOI is an example of such.

This method is defined for support within API's that serve CPRMV metadated publications of which the CPRMV API is a reference implementation and should not be used directly and therefor it is definied in the cprmv-serve namespace.
