# core.python

The core.python method is a type of serialisation method that serves as a basis for the support of Python code as expressions of RuleSet's for any RuleMethod that typically use Python as a serialisation format. To use this, the CPRMV standard provides a cprmv python decorator library.

The regalgo and openfisca methods are examples of such.

This serialisation method is defined for support within API's that serve CPRMV metadated publications of which the CPRMV API is a reference implementation and should not be used directly and therefor it is definied in the cprmv-serve namespace.
