# core.markdown

The core.markdown method is a serialisation method that serves as a basis for the support of Markdown serialisations of RuleSet's for any RuleMethod that typically use Markdown as a serialisation format.

The catala method is an example of such

This serialisation method is defined for support within API's that serve CPRMV metadated publications of which the CPRMV API is a reference implementation and should not be used directly and therefor it is definied in the cprmv-serve namespace.
