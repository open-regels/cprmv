# core.rdf

The core.rdf method is a publication method that serves as a basis for the support retrieval of RuleSet's that have been published as RDF and are retrieveable through HTTP through some reference method that is based on a Linked Data URI strategy.

TOOI is an example of such.

This publication method is defined for support within API's that serve CPRMV metadated publications of which the CPRMV API is a reference implementation and should not be used directly and therefor it is definied in the cprmv-serve namespace.
